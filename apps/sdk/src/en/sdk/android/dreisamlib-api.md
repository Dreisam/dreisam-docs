# Android DreisamLib API

## Overview

DreisamLib is an SDK designed for device connection and data interaction. It provides device connection management, data synchronization, and historical data retrieval for applications that communicate with supported devices.

## Initialization

### Pre-initialization

```java
void preInit(Application context)
```

- Function: Pre-initializes the SDK and must be called on the main thread inside `Application.onCreate`.
- Features:
  - Extremely lightweight and does not affect cold-start performance.
  - Does not collect device information.
- Parameter: `context` - Application context.

### Formal Initialization

```java
void initSDK(String appId, DreisamLibBuilder builder)
```

- Function: Completes the formal initialization of the SDK.
- Call Timing: Can be invoked after pre-initialization; it is required.
- Parameters:
  - `appId` - App ID generated by the open platform.
  - `builder` - Configuration builder.

### De-initialization

```java
void unInit()
```

- Function: De-initializes the SDK and releases related resources.

## Device Connection Management

### Check Connection Preconditions

```java
void checkPreConditions(OnPreCheckListener listener)
```

- Function: Checks system authorization and network authentication before connecting.
- Parameter: `listener` - pre-check listener.

### Connect to a Specified Device

```java
void connectDevice(String deviceInfo)
```

- Function: Connects to the specified device.
- Parameter: `deviceName` - the device name to connect to.

### Set Connection Status Listener

```java
void connectListener(OnConnectListener onConnectListener)
```

- Function: Sets the device connection status listener.
- Parameter: `onConnectListener` - connection status listener instance.

### Check Connection Status

```java
boolean isDeviceConnected()
```

- Function: Checks whether the device is connected.
- Return Value: `true` if connected, `false` otherwise.

### Disconnect

```java
void disconnect()
```

- Function: Disconnects the current device connection.

## Heartbeat Detection

### Start Heartbeat

```java
void startHeartbeat()
```

- Function: Starts device heartbeat detection.

### Stop Heartbeat

```java
void stopHeartbeat()
```

- Function: Stops device heartbeat detection.

## Data Methods

### Set Data Sync Listener

```java
void setSyncDatasListener(OnSyncDatasCallBack callBack)
```

- Function: Sets the data synchronization listener.
- Parameter: `callBack` - sync listener instance.

### Get Historical Data

```java
void getHistory(long startTime, long endTime, OnHistoryDatasCallBack callBack)
```

- Function: Retrieves historical data within a specified time range.
- Parameters:
  - `startTime` - start timestamp in seconds
  - `endTime` - end timestamp in seconds
  - `callBack` - historical data callback

### Set Real-time Data Callback

```java
void realTimeDataCallBack(OnAnalzeDatatListener listener)
```

- Function: Sets the real-time data callback listener.
- Parameter: `listener` - real-time data analysis callback.

## Connected Device Info

```java
DreisamDeviceInfo getDeviceInfo()
```

- Function: Gets the connected device information. Retrieve it 1 second after successful connection.
